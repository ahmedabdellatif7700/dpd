# docker

The `dpd` stage's image (`arof-dpd:local`: CUDA 13.2, sm_87, NVIDIA runtime) and its compose
service `dpd_bb`. `make help` for the targets; `make check` builds and runs the GPU self-test.

Docs: [docs/testbed/jetson/](../docs/testbed/jetson/README.md) (the image, the templates it follows,
the images considered), how to run: [docs/howto/jetson.md](../docs/howto/jetson.md).
